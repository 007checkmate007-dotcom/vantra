# VANTRA

Bursa merkezli sokak giyimi ve parfüm mağazası. Tek dosyalık, sunucusuz e-ticaret arayüzü.

- Tek HTML dosyası, dış bağımlılık yok (yalnızca Google Fonts)
- Misafir gezinme, satın almada kayıt/giriş
- Hesap verileri tarayıcıda AES-GCM ile şifreli (anahtar PBKDF2, 150.000 tur)
- Ödeme: havale/EFT — kart bilgisi hiçbir aşamada toplanmaz
- Sipariş, WhatsApp veya e-posta ile satıcıya iletilir

Katalog şu an **örnek veriyle** doludur. Gerçek ürünleri girmek için uygulama içindeki
**Yardım → Kurulum** sayfasına bakın.
